# Student Server
A a simple Nestjs server which manages students in a postgres database using the RestAPI and GraphQL.
# Tools
### Tools and frameworks I used for building this project
- Nest with
  - REST through Express
  - GraphQL through Apollo
  - OR-Mapping through TypeORM in PostgresSQL and pgAdmin
- Typescript, ESLint, Prettier, SonarQube
- Vitest for integrationtests and Playwright for test coverage
- npm as package manager and task runner
- Docker-Image and Docker Compose
- Git
- Jenkins (CI/CD)
- Postman
